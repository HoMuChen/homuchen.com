用 Claude Code 對話式記帳，4 步就能跑起來，不用會寫程式 👇

會講「中午便當 120」就會用了。連第一步的設定，都可以叫 Claude Code 自己建。

---

1️⃣ 開一個 Claude Code project，放一個記帳檔
expenses.md 或 expenses.csv 都行，看你習慣。

2️⃣ 在 CLAUDE.md 寫清楚規則
記帳檔在哪、格式長怎樣、有哪些分類、自動分類規則（例如「跟客戶」→ 業務交際）。

這步是關鍵：Claude Code 每次開新對話都會讀 CLAUDE.md，就不用每次重新解釋。

懶得寫就跟它說「幫我建一個記帳系統，欄位包含日期、金額、項目、分類」，它會自己寫好～

---

3️⃣ 開啟 Remote Control
桌機的 session 開 Remote Control，手機下載 Claude App、登同一個帳號，就能直接跟桌機的 Claude Code 對話。

不用開電腦、不用 VPN、不用 SSH，跟傳 LINE 一樣。

4️⃣ 邊用邊調
第一週一定會有分錯的，直接說「以後遇到 XX 就分類成 YY，更新到 CLAUDE.md」，它會自己把規則寫進去。

越用越懂你 🎉

---

要報稅或給家人看也行：一句「幫我把這個月的帳轉成 Excel，按分類分頁」就生出來。
