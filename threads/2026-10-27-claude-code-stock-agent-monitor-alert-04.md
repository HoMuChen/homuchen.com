我的台股 AI agent 會選股、會盯盤，
但有一件事我刻意不讓它做：下單。

它做到「發訊號通知我」為止。
要不要進場、買多少，是我自己看了再決定。
一來是風險，二來我也還沒那麼信任任何全自動的東西。

它真正幫我省下的，是「盯盤」這件最耗注意力的事：
不用整個早上開著看盤軟體，也不會因為在忙，錯過早上選好的那幾檔。

把注意力交出去，決定留在自己手上。
