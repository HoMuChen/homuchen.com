跟客戶在全家咖啡座談了 4 小時，買了 200 元咖啡和點心。

記帳 App 會把它歸成什麼？
「便利商店」。

因為它的自動分類基本上是關鍵字比對：看到「全家」就是便利商店 🤷

但這筆明明是業務交際。

換成 LLM 就不一樣了。我跟 Claude Code 說「剛跟客戶在咖啡廳，咖啡和茶點 480」，它看到「跟客戶」三個字，直接分成業務交際。

分錯也沒關係，下一句講「那是個人的，改成餐飲」就修好。
再多一句「以後遇到 XX 就分類成 YY，更新到 CLAUDE.md」，規則就寫進去，下次照做。

App 的分類規則是廠商寫的，
這套的規則是我自己定的。
