檢查 agent 指令有一招超好用：

把裡面所有「好好」「適當」「重要的」圈起來。

每圈到一個，就停下來問自己：具體是什麼？

「重要的再通知我」
→「單日漲跌幅超過 5% 才通知我」

「量大的時候提醒我」
→「成交量到 20 日均量 2 倍以上」

這種話對人類同事都嫌空了，何況 agent 🤔

你覺得「這還用講嗎」的地方，正是 agent 最會猜錯的地方。
