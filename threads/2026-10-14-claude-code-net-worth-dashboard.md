「我現在到底有多少錢？」

這個問題我以前答不出來。

不是因為錢太多😂 是因為資產散在好幾個地方：股票在券商 App、現金在不同銀行，有房貸的話還要另外算剩多少本金。

每次想知道總數，就是一個一個 App 打開、抄數字、加起來。

所以某天早上，我叫 AI Agent 幫我做了一個淨資產儀表板 👇

---

先說我以前的做法：2021 年我做過一張 Google Sheet 股票損益表，用 GOOGLEFINANCE 抓股價。

用久了三個問題：

1️⃣ 它只管得到股票，其他資產都要手動填，一格忘了更新總數就錯
2️⃣ 只看得到「現在」，看不到淨資產這三個月是變多還是變少
3️⃣ 手機上看要放大、拖來拖去

我要的很單純：打開手機，第一眼就看到淨資產。

---

現在的樣子：

📊 首頁第一眼就是淨資產，下面是總資產、總負債、負債比
📈 台股、加密貨幣自動抓報價，外幣自動換算成台幣
🏠 房貸輸入一次撥款日、利率、年限，剩餘本金每個月自己算
🗓 每天 23:55 自動存一次快照，畫成淨資產走勢圖
📱 做成 PWA，手機「加入主畫面」就像一個 App

---

最酷的是，這整個專案我一行程式都沒自己寫。

看 git 紀錄：
10:06 建專案
10:21 總覽頁已經能看
10:47 補完登入安全（防暴力破解）
12:21 部署上線

一個早上、20 個 commit、大約 3,800 行 TypeScript，全部是 Claude Code 寫的。我做的事比較像 PM：把需求講清楚，看它做得對不對。

---

做的過程中，有幾個設計我覺得用 Google Sheet 做資產表也受用：

✅ 房子算「淨值」：市值減掉房貸剩餘本金，不是市值
✅ 合約只算「權益」，不算名目價值，不然淨資產會被槓桿灌水
✅ 報價抓不到就退回收盤價並標示清楚，寧可舊，也不要錯了還不知道
✅ 串券商 API 只用唯讀金鑰，外洩了也沒人能拿去下單
