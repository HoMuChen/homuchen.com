叫 Claude Code 寫完 script 之後，我一定會多補一句：
「把這支腳本的用法寫進 CLAUDE.md。」

差別很大。

下次開一個新對話，它讀到 CLAUDE.md，就知道這個 project 在做什麼、每支腳本怎麼跑，不用我從頭再解釋一次。

我的台股追蹤 project 連持倉格式也這樣處理：
「設計一個持倉記錄的格式，把說明寫進 CLAUDE.md，這樣我說『我買了 XXX 均價 OOO』的時候，你就知道怎麼記。」

之後每次說我買了什麼，它都照同一個格式記，不會這次一個樣、下次又一個樣 ✅

AI 每次開新對話都是失憶的，
CLAUDE.md 就是你留給它的交接文件。
