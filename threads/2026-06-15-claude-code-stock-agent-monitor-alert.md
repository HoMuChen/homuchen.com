盤中我在開會，手機突然震了一下。

是我那隻台股 bot 傳來的 Telegram：

🔔 2330 台積電【波動率擠壓】
✓ 突破上軌　✓ 量能達標　✓ 5 日動量轉正

重點是——那個當下我完全沒在看盤。

是它早上自己選好今天要盯的股票，盤中每 10 分鐘檢查一輪，等條件全到齊，才主動敲我 👇

---

這隻 agent 的一天，我用 crontab 給了它一張作息表，它自己醒來四次：

🌅 08:00 盤前 → 掃全市場、選出今天要盯的股票
📈 09:00–13:30 盤中 → 每 10 分鐘盯盤
🌙 18:00 收盤 → 補當天股價
🌃 22:00 盤後 → 補三大法人籌碼

補資料 → 選股 → 盯盤發訊號，天天自己跑，我不用碰。

---

盤中那隻是整套的核心。

它只在「該滿足的條件全部滿足」時才通知我——突破上軌＋量能達標＋動量轉正，全部成立才算數。

接近但還沒到齊的，只默默寫進 log，不吵我。

因為通知如果太吵，你最後一定會把它靜音，那就等於沒做。

---

你可能會想：選股策略誰都會喊，準不準才是問題。

所以每個策略都是先通過全市場回測才被放進去的：約 2369 檔全驗、一定算進手續費和交易稅、參數還要夠穩健。

活下來的 14 個策略，挑 3 個組成投資組合回測：年化約 +34%、最大回撤 9.1%、Sharpe 2.58。

---

但我得很誠實：這是回測數字，不是我的對帳單，更不是未來保證 🙏

而且這隻 agent 不會幫我下單——它做到「發訊號通知我」為止，要不要進場、買多少，是我自己看了再決定。

它幫我省下的，是「盯盤」這件最耗注意力的事，不是幫我賺錢。

---

最酷的是——這整套我幾乎沒自己寫 code，是「出一張嘴」讓 Claude Code 去實作的。
