我用 Claude Code 一天做出自己的 AI 助理：下午一點多開空 repo，晚上 11 點上線。

能這麼快，最關鍵的不是寫程式，是開工 40 分鐘後我講的這句話：

「我希望它至少可以把外部訊息跟資料收集完整，先不需要做什麼處理跟分析沒關係，只要我的 agent 可以讀取資料庫，就可以根據這些資料做回答跟分析。」

一句話砍掉一大塊工作。
系統只負責「收」，聰明的事交給 agent。

AI 把「做出來」的成本降到很低之後，真正的功夫變成：知道哪些先不要做。
