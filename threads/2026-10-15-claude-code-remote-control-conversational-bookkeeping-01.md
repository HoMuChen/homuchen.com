記一筆帳，以前要 4 個動作：
打開 App → 選分類 → 填數字 → 按儲存

現在只剩一句話：
「中午便當 120」

我把用了 5 年的 Google Sheet 記帳收掉了，也沒換成記帳 App。
現在是手機開 Claude Code Remote Control，直接跟家裡電腦上的 Claude Code 講話，它自己分類、寫進記帳檔 ✅

用了幾個月：
📉 每天記帳時間從 1-2 分鐘 → 10 秒以內
🎯 分類正確率約 9 成，分錯講一句就改好

記帳這件事，終於不用「打開什麼」了 😎

完整做法放留言～
