Google Sheet 最值錢的能力，其實已經被 AI 拆掉了。

以前記帳要用試算表，是因為「視覺化」得先有結構化的表格才做得出來。

現在我的帳只是一個 markdown 檔。
月底跟 Claude Code 說「幫我做這個月的支出分類圖」，它讀檔、加總、畫圖，幾秒鐘。
想知道「最近三個月餐飲有沒有變多」，問就有答案 📊

我把這叫 On-Demand Visualization：
資料在系統裡就夠了，圖是想看才生，不是預先做好的。

dashboard 不會消失，但會退到「每天固定要看的核心指標」。
其他臨時想知道的事，直接問就好。

你現在手上的 dashboard，有幾張是真的每天在看的？🤔

---

固定每個月都要看的圖（像月支出總覽），我會叫 Claude Code 把生成程式存成 script，下次跑一次就出圖，不用每次重生～
