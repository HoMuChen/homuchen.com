# Claude Cowork 實戰課 — 課程大綱 v2

---

## 課程總覽

- **總時數：8-10 小時**
- **章節數：8 章 + Bonus**
- **核心理念：每一章都有實作 demo，不只是講概念**

---

## 第一章：認識你的 AI 同事（45 分鐘）

### 觀念
- AI 聊天 vs AI 做事：ChatGPT 是顧問，Cowork 是員工
- Cowork 的運作邏輯：資料夾 + 指令 + 自主執行
- 跟 n8n / Zapier 的差別：為什麼不需要學另一個平台

### 實作 Demo
- 安裝 Claude Desktop、切換到 Cowork 模式
- 選定第一個資料夾（用 Downloads 當示範）

### 案例 Demo ①：下載資料夾大掃除
把一個塞滿各種檔案的下載資料夾丟給 Cowork，讓它自動辨識內容、分類、重新命名。觀眾 5 分鐘內就能看到「哇，它真的在動」的效果。

---

## 第二章：建立你的 AI 知識庫（1 小時）

### 觀念
- 什麼資料該放進知識庫？（服務說明、報價、FAQ、SOP、過去案例）
- 資料夾結構設計：怎麼讓 AI 找得到、看得懂
- 文件格式的眉角：Markdown vs Word vs PDF，哪個 AI 最好消化

### 實作 Demo
- 從零建立一個業務知識庫資料夾
- 把散落的公司資料整理成結構化文件
- 測試：丟一個客戶問題，看 Cowork 能不能從知識庫裡找到正確答案

### 案例 Demo ②：接案報價自動回覆
建立一個自由工作者的知識庫（服務項目、定價邏輯、過去報價範例），然後模擬三種不同的客戶詢問，展示 Cowork 每次都能產出精準、語氣對的回覆信。

---

## 第三章：Skill — 教 AI 你的做事方式（1.5 小時）

### 觀念
- 什麼是 Skill？為什麼它是 Cowork 最強大的功能
- SKILL.md 就是你 AI 員工的「工作手冊」
- Skill vs 普通 prompt 的差別：一次設定、永久生效
- Skill 的結構拆解：角色定位、做事規則、輸出格式、品質標準

### 實作 Demo
- 從零寫一份 SKILL.md
- Skill 的最佳實踐：怎麼寫得讓 AI 真的聽話
- 測試有 Skill vs 沒有 Skill 的輸出差異（同一個任務，品質天差地遠）

### 案例 Demo ③：品牌內容產出 Skill
建立一個「品牌內容寫手」Skill，餵入品牌風格指南（語調、用字偏好、目標受眾），然後讓 Cowork 用這個 Skill 批量產出一週份的社群貼文。展示有 Skill 跟沒 Skill 的對比——沒 Skill 的像 AI 罐頭文，有 Skill 的像你自己寫的。

### 案例 Demo ④：客服回覆 Skill
建立一個「客服專員」Skill，定義回覆語氣、知識範圍、遇到不確定的問題要怎麼處理（轉人工 / 請客戶留資料）。模擬五種客戶問法，展示 Skill 怎麼讓 AI 的回覆穩定又專業。

### 延伸
- 多個 Skill 並存：不同任務用不同 Skill
- Skill 的版本管理：怎麼迭代優化你的 AI 工作手冊

---

## 第四章：Connectors — 串接你的工具（1.5 小時）

### 觀念
- Connectors 是什麼？讓 Cowork 不只操作本地檔案
- Web Connectors vs Desktop Extensions 的差別
- 安全性：連了之後 AI 能看到什麼？怎麼控制權限

### 實作 Demo — Google 系列
- 串接 Google Drive：讓 Cowork 讀取雲端文件
- 串接 Google Sheets：讓 Cowork 查詢和更新試算表
- 串接 Gmail：讓 Cowork 掃描信箱、分類郵件

### 案例 Demo ⑤：會計事務所的報價查詢系統
串接一份 Google Sheets 報價表，模擬客戶問「公司登記多少錢？」「記帳一個月費用？」，Cowork 從試算表裡抓出對應的報價，產出一封完整的回覆。

### 案例 Demo ⑥：Email 收件匣自動整理
串 Gmail，讓 Cowork 掃描今天的收件匣，分成「緊急回覆」「今天處理」「參考就好」三類，對緊急的信件產出建議回覆草稿。

### 實作 Demo — 瀏覽器
- 串接 Claude in Chrome
- 讓 Cowork 在網頁上搜集資料

### 案例 Demo ⑦：競品分析報告
給 Cowork 三個競品的官網 URL，讓它用瀏覽器爬取定價和服務內容，結合你本地的報價資料，產出一份「競品 vs 我們」的分析報告。

---

## 第五章：排程與自動化 — 讓 AI 自己跑（1 小時）

### 觀念
- 排程功能：一次設定，每天 / 每週自動執行
- 什麼任務適合排程？什麼不適合？
- Global Instructions：讓 Cowork 記住你的偏好

### 實作 Demo
- 設定第一個排程任務
- Global Instructions 的寫法

### 案例 Demo ⑧：每日晨間簡報
設定排程：每天早上 Cowork 自動掃描信箱重點、查看今日行事曆、整理產業新聞，產出一份「今日簡報」放在桌面。

### 案例 Demo ⑨：每週法規追蹤報告
設定每週一自動掃描財政部、國稅局的最新公告，整理成一份摘要報告，放到 Google Drive 指定資料夾，同時寄一封通知信給團隊。

---

## 第六章：Projects — 管理多條業務線（45 分鐘）

### 觀念
- Project 是什麼？為什麼需要把不同業務分開
- Project vs 單一資料夾的差別：獨立的指令、上下文、記憶
- Project 的架構設計：怎麼切分最合理

### 實作 Demo
- 建立第一個 Project
- 設定 Project 專屬的指令和資料夾
- 在不同 Project 之間切換

### 案例 Demo ⑩：一人公司的三個 Project
示範一個自由工作者怎麼用三個 Project 管理不同面向：「客戶專案管理」（追蹤每個案子的進度和文件）、「內容行銷」（部落格 + 社群貼文產出）、「財務記帳」（發票整理 + 月報產出）。

---

## 第七章：Plugins — 產業專用的擴充功能（45 分鐘）

### 觀念
- Plugin 是什麼？跟 Connector 和 Skill 的差別
- Plugin = Skill + Connector + Sub-agent 的打包組合
- 怎麼找到適合你產業的 Plugin
- 自訂 Plugin 的可能性

### 實作 Demo
- 瀏覽 Plugin 市集、安裝第一個 Plugin
- 設定和自訂 Plugin 的參數

### 案例 Demo ⑪：用 Plugin 打造完整的客戶 Onboarding 流程
示範安裝一個專案管理類的 Plugin，然後建立一套自動化的客戶 onboarding：新客戶進來 → 自動建立資料夾 → 產出歡迎信 → 建立 checklist → 排程催收必要文件。

---

## 第八章：進階技巧與成本控制（45 分鐘）

### 觀念
- Token 用量怎麼算？怎麼看自己花了多少
- 省 token 的實用技巧：指令怎麼寫最精簡
- Cowork 做錯了怎麼辦？錯誤排除指南
- 安全注意事項：哪些資料不該給 AI 看

### 實作 Demo
- 查看 token 使用量
- 同一個任務，不同寫法的 token 消耗比較
- 建立「安全邊界」：設定 Cowork 不能做的事

### 案例 Demo ⑫：最佳化一個既有的工作流
拿第五章做的排程任務，示範怎麼優化指令、減少不必要的步驟、降低 token 消耗，同時維持輸出品質。

---

## Bonus 章：產業實戰案例庫（1.5 - 2 小時）

前面 8 章已經 demo 了 12 個案例，這裡再補充更多「看了就能抄」的實戰場景。每個案例都附上完整的設定（SKILL.md + 資料夾結構 + 指令範本），學員可以直接複製到自己的 Cowork 裡改一改就用。

### 會計事務所篇
- ⑬ 50 份 PDF 發票自動辨識、重新命名、產出 Excel 彙整表
- ⑭ 報稅季資料催收：根據 checklist 自動產出每個客戶的缺件通知信
- ⑮ 新進員工的訓練教材：從散落的筆記和 SOP 截圖自動整理出完整教學文件

### 電商賣家篇
- ⑯ 50 個商品描述批量產出：照片 + 規格 → 品牌語調的文案
- ⑰ 客戶評價分析：爬取各平台評價 → 正負面趨勢 + 高頻抱怨點 + 改善建議
- ⑱ 一週份社群貼文排程：給主題和促銷訊息 → IG / FB 文案 + hashtag + 配圖建議

### 自由工作者篇
- ⑲ 月底收據整理：截圖丟進去 → 自動辨識金額、日期、廠商 → Excel 記帳表
- ⑳ 客製化提案簡報：客戶需求 + 過去案例 → 自動產出 PPTX 提案檔
- ㉑ 個人品牌內容產線：風格指南 + 主題 → 部落格草稿 + 電子報 + LinkedIn 貼文

### 設計公司篇
- ㉒ 作品集描述撰寫：專案照片 + 筆記 → 官網用的案例介紹文案
- ㉓ 客戶需求整理：通訊記錄 + 會議筆記 → 結構化需求文件
- ㉔ 工時估算與報價單：歷史工時資料 + 新案需求 → 自動報價

### 跨產業通用篇
- ㉕ 會議紀錄 → 行動項目追蹤文件
- ㉖ SOP 文件化：散落的筆記和截圖 → 新人看了就能上手的 SOP
- ㉗ 研究報告自動產出：給主題 → 網路搜集 + 本地文件 → 結構化報告
- ㉘ 季度業務回顧報告：拉取多份月報資料 → 產出趨勢分析和建議
