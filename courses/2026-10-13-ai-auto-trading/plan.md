## 一、定位

- **一句話：** 用 Claude Code 把一個交易想法，做成會自己下單、出錯會自己停下來的系統。
- **教什麼：** 工具打造的流程（資料 → 研究 → 回測 → 提醒 → 下單 → 安全機制 → 維運）。
- **不教什麼：** 不報明牌、不推薦個股、不提供「穩賺策略」、不承諾報酬。課程裡的網格策略是**教學案例**，不是投資建議。
- **差異化（市場觀察，2026-10-06）：**
  - 繁中「程式交易 / Shioaji」內容以傳統 Python 手寫教學為主（iThome 鐵人賽系列），沒有「叫 AI agent 寫下單程式」的角度。
  - 「Claude Code 自動交易」課程只見英文 / 韓文，繁中空白。
  - 作者自己有真錢在跑的系統，課程裡的每個 bug、每道安全機制都是真的修過、真的加上去的。

## 二、目標受眾

**適合：**
- 看過 FinMind / 台股 AI Agent 文章，已經會開 terminal 跑 Claude Code
- 已經有「看盤通知」，想再往「自動下單」走一步
- 有自己的交易想法，想用資料驗證，而不是憑感覺

**不適合：**
- 想找「買了就會賺」的策略（這門課最大的收穫之一是學會懷疑好看的回測😂）
- 完全沒有交易經驗、不了解期貨風險的人（建議先看 #3 個股期貨入門、先用現股）
- 不願意自己看懂程式在做什麼、只想複製貼上直接上實盤的人

## 四、課程形式與定價（草案）

**早鳥價 NTD 4,980**（原價 NTD 6,980）

包含：
- 完整課程影片（6–8 小時，7 章 + Bonus）
- 教學用範例專案（資料層、回測、提醒、下單、安全機制骨架；參數為教學值）
- 每章的 Claude Code 對話 prompt 範本
- 專屬 LINE 社群（問問題 + 券商 API 變動時更新）

定價理由：比 Claude Cowork 實戰課（早鳥 3,980）多一個硬技術門檻與券商串接；比市面程式交易課（常見萬元以上）便宜，但用 AI 縮短手寫程式的學習時間。

**升級選項（之後再評估）：** 1 對 1 系統健檢（看學員自己的策略與安全機制）→ 銜接 [AI Agent 諮詢與代建服務](/ai-automation-workflow/)。

## 五、法規與風險邊界

- 課程定位為「軟體工具打造」，不涉及投資顧問：不針對個別學員給買賣建議、不推薦標的、不提供訊號。
- 銷售頁與每章開頭都放風險揭露：期貨有槓桿、可能損失超過保證金；回測不代表未來。
- 作者實盤：只說「自己有真錢在跑」，不公開本金、報酬率、實盤參數。
- Shioaji 申請與 API 同意書流程以官方文件為準，課程只做文字與流程說明。

# 用 AI 打造自動化交易系統

### 不是教你一個會賺錢的策略，是教你讓 AI 幫你把策略做成系統，而且出事會自己停下來

---

不知道大家有沒有這樣的經驗？

有一個交易想法，覺得「應該會賺吧」，但從來沒驗證過。好不容易學會寫個看盤通知，訊號來了還是要自己盯、自己下單，上班開會一忙就錯過了。

我也是這樣走過來的。

一開始我只是用 Claude Code 串 FinMind 抓股價，後來做了會自己選股、盯盤、發 Telegram 的 AI Agent，最後跨出了最可怕的那一步：**讓它自己下單**。

整個過程我幾乎沒有自己寫程式碼。但我修過的 bug 一個比一個嚇人——回測多算了不存在的獲利、槓桿上限其實沒擋住、轉倉順序寫反……**它們沒有一個會報錯。**

所以這門課的重點不是「AI 好厲害」，而是：

> **AI 幫你把「寫」這件事變快了，但「確認它是對的」還是得你來做。**

## 這門課會帶你做什麼

1. **資料層**：用 FinMind 拿到乾淨的資料，避開默默被截斷的坑
2. **策略研究**：叫 Claude 幫你做實驗、寫研究筆記
3. **回測與防過擬合**：成本、轉倉、參數高原、群組驗證
4. **提醒模式**：先讓它喊，不讓它下
5. **下單模式**：永豐 Shioaji 串接、限價單、撤單、轉倉
6. **安全機制與對帳**：9 道保險，把 AI 關在籠子裡
7. **上線維運**：排程、log、異常通知、什麼時候該關掉它

Bonus：網格進階手法實測——移動停利有效、RSI 過濾是毒藥。

## 常見問題

**Q：我不會寫程式可以上嗎？**
可以，但你要願意「看懂」AI 寫的東西在做什麼。課程全程用對話叫 Claude Code 寫，重點放在怎麼問對問題、怎麼驗證。

**Q：一定要用永豐嗎？**
第 1–4 章不需要券商帳戶。第 5 章以 Shioaji 示範，因為它是台灣第一個有官方 AI coding agent skill 的券商 API；其他券商 API 的思路相同。

**Q：上完課就能賺錢嗎？**
不能保證，也不應該有人跟你保證😂 這門課教的是把工具做出來、做得安全。我自己的回測研究裡，網格策略甚至輸給買進持有——課程會誠實告訴你為什麼。

**Q：需要多少本金？**
課程不討論本金規模，也不建議新手一開始就用期貨。可以先只跑到提醒模式，或用現股、模擬環境練習。

**Q：Claude Code 要付費嗎？**
需要 Claude Pro 以上方案。
