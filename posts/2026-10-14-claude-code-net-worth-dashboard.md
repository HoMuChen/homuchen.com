2021 年的時候，我寫過一篇 [**[Google sheet] 我如何製作股票損益表，自動抓取最新股價**](/posts/google-sheet-stock-income-statement/)，那張表我用了好一陣子。

但用久了就發現，它只解決了「股票」這一塊。我真正想知道的其實是另一個問題：

> **我現在到底有多少錢？**

這個問題聽起來很簡單，回答起來卻很麻煩。資產一多，就會散在好幾個地方：股票在券商 App、現金在不同銀行、有人還有加密貨幣、有房貸的還要另外算剩多少本金沒還。每次想知道總數，就得一個一個 App 打開、抄數字、加起來😫

所以某天早上，我決定把它做成一個網站。而且跟之前一樣，**程式不是我自己寫的，是我叫 AI Agent（Claude Code）寫的，一個早上就做完了。**

## 個人資產負債表是什麼？淨資產怎麼算？

**個人資產負債表，就是把你「擁有的東西」跟「欠別人的錢」列在一起，兩者相減就是你的淨資產（淨值）。**

公式只有一行：

> 淨資產 = 總資產 − 總負債

- **總資產**：現金、股票、基金、加密貨幣、房地產市值……所有換得成錢的東西
- **總負債**：房貸、車貸、信貸、信用卡未繳款……所有你還要還的錢

舉個例子：一間市值 1,200 萬的房子，房貸還剩 850 萬，這間房子對淨資產的貢獻是 350 萬，而不是 1,200 萬。

很多理財書都會建議定期做一次個人資產負債表，因為**收入高不代表有錢，淨資產有沒有長大才是**。

把所有資產放在同一張表上還有一個好處：它會打破「心理帳戶」。我在 [**《金錢心理學》讀書筆記**](/posts/book-note-money-psychology/) 裡寫過，我們很容易把錢分類，覺得「交易所裡那筆是閒錢」「這個帳戶的錢不算」。但**錢就是錢**，全部換算成同一個數字擺在一起，才看得出自己真正的狀況。

問題是，「定期」這兩個字最難。

## 為什麼我不用 Google Sheet 做資產負債表了？

網路上搜「個人資產負債表」，大部分教的是下載一份 Excel 或 Google Sheet 範本，每個月填一次。我也這樣做過，最後都放棄了，原因有三個：

**1. 資產散在太多地方，Sheet 只管得到一部分。**
股價可以用 `GOOGLEFINANCE` 抓（雖然台股常常 `#N/A`，這件事我在 [**FinMind 那篇**](/posts/claude-code-finmind-stock-tracking/) 抱怨過了😂），但加密貨幣、外幣、房貸剩餘本金，都要自己手動更新。只要有一格忘了更新，整張表的總數就是錯的。

**2. 看不到淨資產的走勢。**
試算表只會告訴你「現在」是多少。想看過去三個月是變多還是變少，就要自己每天複製一份存起來，這種事很難持續。

**3. 手機看很痛苦。**
我最常想看總數的時候，通常都不在電腦前。Google Sheet 在手機上要放大、拖來拖去，看一個數字很費工。

我要的其實很單純：**打開手機，第一眼就看到淨資產，往下滑就看到走勢跟配置。**

股票頁就是我 2021 年那張 Google Sheet 損益表的樣子：股數、現價、成本、未實現損益、佔比。差別是報價會自己更新，而且不會再 `#N/A` 了。

### 房貸：剩多少本金，自己算

這是我覺得 Google Sheet 最難做好的部分。房貸每個月都在變，要算剩餘本金得套攤還公式，大部分人的資產表就直接填「貸款總額」，越填越不準。

這裡只要輸入一次撥款日、利率、年限，它每個月會自己算出剩餘本金、月付金、已經還了幾期。有提前還款的話，也可以手動覆寫剩餘本金。

## AI Agent 一個早上是怎麼寫出來的？

**整個專案我一行程式都沒有自己寫。** 我做的事情，比較像產品經理：把需求講清楚、看它做出來的東西、告訴它哪裡要改。

看 git 紀錄最清楚。這是那天早上的時間軸：

| 時間 | 做了什麼 |
|------|---------|
| 10:06 | 建立專案 |
| 10:09 | 資料層：資料庫、報價抓取、房貸計算、每日快照 |
| 10:10 | 登入密碼、更新報價的 API |
| 10:14 | 總覽頁、各類資產頁、歷史快照頁 |
| 10:20 | Docker 部署設定和說明文件 |
| 10:33 | 加上加密貨幣合約帳戶 |
| 10:47 | 加強登入安全：隨機 session、防暴力破解 |
| 12:21 | 部署到我自己的主機上線 |

從建專案到「可以用」，大概 15 分鐘；到加完安全機制、真的部署上線，一個早上。整個專案大約 3,800 行 TypeScript，20 個 commit。

用的技術很普通：[Next.js](https://nextjs.org/)、SQLite（資料就是一個檔案）、Recharts 畫圖。重點不是技術多厲害，而是**我只需要知道自己要什麼**。

### 需求其實就這幾條

整理起來，我要的就是這幾條：

- 一頁看到淨資產，所有資產都換算成台幣
- 台股、加密貨幣要自動抓報價，不要讓我手動填
- 房貸要自己算剩餘本金，不要讓我每個月改數字
- 每天自動存一次快照，我要看走勢
- 手機要好用
- 這是我的財務資料，**登入一定要做好**

最後一條很重要。這個網站是放在網路上的，所以 10:47 那個 commit 專門在補登入安全：每次登入產生隨機的 session、資料庫只存雜湊值、同一個 IP 15 分鐘內錯 5 次就鎖 15 分鐘、全站錯太多次就暫停所有登入。放在網路上的財務資料，這些一定要有。

### 有哪些設計值得偷學？

就算你不打算自己做，下面這幾個設計，拿去用 Google Sheet 做資產表也一樣受用：

1. **合約、期貨只算「權益」，不算「名目價值」。** 開 10 倍槓桿的合約，名目價值很大，但真正屬於你的只有保證金加上未實現損益。把名目價值算進資產，淨資產會被嚴重高估。（期貨保證金跟槓桿的概念，我在 [**個股期貨入門**](/posts/stock-futures-tsmc-mini-futures-guide/) 那篇有寫。）
2. **房產算「淨值」，不算市值。** 跟前面的例子一樣，市值減掉房貸剩餘本金，才是你的。
3. **報價抓不到時，寧可退回收盤價並標示清楚，也不要顯示錯的數字。** 資產表最怕的不是不準，是「錯了你還不知道」。
4. **串券商 API 時，只用「唯讀」的金鑰。** 儀表板只需要讀帳戶餘額，申請 API 金鑰時就不要開交易權限。就算金鑰外洩，別人也沒辦法拿它下單。
5. **手機版不快取任何資產數字。** 斷線時只顯示離線頁面，不會讓你看到一份過時的數字還以為是最新的。

## 為什麼這次我選擇做 Dashboard？

如果你有看過我的 [**Claude Code 對話式記帳**](/posts/claude-code-remote-control-conversational-bookkeeping/) 那篇，可能會覺得奇怪：我那時候說「dashboard 開始被 on-demand 取代」，怎麼現在又做了一個 dashboard？

其實那篇也有講到：**dashboard 不會消失，它會退到「每天固定要看的核心指標」這個角色。**

淨資產就是這種指標。我每天都想看一眼，而且永遠是看同樣那幾個數字，這種情況做成一個固定的頁面最省事。反過來，「上個月餐費花多少」「這筆支出算哪一類」這種臨時想到的問題，還是用對話問 AI 比較快。

> **記帳是「流量」，用對話處理；資產是「存量」，用儀表板一眼看完。**

## 常見問題

### 個人資產負債表多久更新一次比較好？

用手動的 Excel 或 Google Sheet，大部分建議**每個月或每季**做一次，太頻繁很難持續。如果像這個儀表板一樣能自動抓報價、每天自動存快照，就不用煩惱更新頻率，只要偶爾補一下現金餘額就好。

### 淨資產要包含自住的房子嗎？

看你的目的。如果想知道「如果今天全部賣掉，我有多少錢」，就要算進去，但要用**市值減掉房貸剩餘本金**的淨值。如果你更在意「可以動用的錢」，可以另外看「流動資產」（現金、股票、加密貨幣），這個儀表板兩個都會顯示。

### 把財務資料放在網路上安全嗎？

這是自架的網站，資料只存在我自己主機上的一個 SQLite 檔案裡，不會經過任何第三方記帳服務。登入有做 session 與防暴力破解，券商只用唯讀金鑰。如果你還是不放心，也可以只在自己電腦上跑，不要放到網路上。

### 我不會寫程式，可以做嗎？

可以，這就是我想分享的重點。你需要的是**把需求講清楚的能力**，以及看懂它做出來的東西對不對。如果你想先體驗這種「出一張嘴」的開發方式，可以看我的 [**Vibe Coding 做網頁完整實戰**](/posts/vibe-coding-build-portfolio-website/)。

### 跟記帳 App 的資產功能有什麼不一樣？

記帳 App 通常也有資產頁，但能接的帳戶、能算的東西都是 App 決定的。自己做的好處是**完全照你的需求長**：想加什麼資產類型、想怎麼算，跟 AI 講一聲就好，而且資料都在你自己手上。

## 結語

從 2021 年那張 Google Sheet 股票損益表，到今天這個一打開就看得到淨資產的儀表板，中間我自己寫的程式碼是零。
